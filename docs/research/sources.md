# Research sources

Research date: **12 October 2026**. Source IDs are stable references used by the CSV files. These are primary publisher, manufacturer, governing organization, or project-maintainer sources. Manufacturer material establishes equipment categories and reported measurements; it does not establish comparative health benefits.

The catalogs are an original product-planning synthesis. An equipment row's source supports its **family**, not necessarily every named variation or every exercise that can use it. Candidate exercises still need individual technique, equipment-compatibility, and editorial review before publication. No source images, videos, exercise descriptions, or complete third-party dataset were imported.

## How to maintain this evidence

Recheck sources when implementing a family, when vendor terms change, and before publishing any event-specific template. Record exact model manuals for machine settings. Pin dataset revisions and store entry-level author, license URL, source URL, media provenance, and attribution text before importing content. Broken or blocked sources should stay visibly marked; an unavailable page is not verified evidence.
