## Actual numeric verification

`tests/responsive-numeric.spec.js` waits for the actual loaded DM Sans face and measures an independent DOM span with the input's explicit font, numeric features and spacing. It compares glyph width with the measured content area after padding/borders, checks exact displayed values in blurred/focused states, and verifies 44×44 Done controls inside the row/viewport with a center hit test. It also checks 16 px text, minimum 24 px input width/44 px height and page/row containment.
