## Resolved physical keyboard fixture

Physical baseline `AccountExperienceTests/testSignInSubmitWaitsForAnEmailAndAPassword` failed at the final enabled-submit assertion. The captured frame shows the expected synthetic email and an empty Password field with “Enter your password.” No request was submitted. The theory that malformed email remained was disproven by the image. Repeated diagnosis showed that the current keyboard had no x key and ASCII event delivery left the secure field empty. The portable visible-letter fixture passes on unchanged baseline and final code with all original validation assertions and added exact-input checks preserved. The original failed result is retained.
